# Zoval Spaces

A personal Android app written in Kotlin.

## Planned features

- A wake-up alarm with a dismissal step that requires active input.
- A finance tracker that calculates balances from manually entered income and expenses.

## Run the starter

Open the repository in Android Studio. Use JDK 17 and install Android SDK
Platform 36. Select the `app` run configuration and run on an emulator or
phone with Android 8.0 (API 26) or newer.

Build a debug APK from PowerShell with `./gradlew.bat :app:assembleDebug`.
